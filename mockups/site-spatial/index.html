// AI voice assistant · Raspberry Pi 5

ClawVIS

Flagship
Always-on voice assistant running on a Raspberry Pi 5 using a three-layer routing system to make it feel instant. The wake word, speech-to-text, and Piper's "JARVIS" voice run on-device; a quick intent matcher answers frequent commands and drives Home Assistant to turn lights and devices on and off without a round trip to the cloud; anything more complex is delegated over SSH to the home server, waking it up over the network if needed. This server agent is called Claw, hence the name (Claw + JARVIS). Also includes an application that can be installed on a phone: a cockpit with push-to-talk chat, a system HUD with a WebGL energy orb reacting to your voice, and an Obsidian-like memory graph over the notes vault that keeps the two-way sync between the Pi and the server.

// desktop app · local AI · 2026

LlamaChat

Cross-platform desktop application benchmarking your hardware: CPU, GPU, VRAM, RAM, instruction set, then rating all available models from "won't even run" to "flying" for your exact hardware rather than based on spec sheets. Choose a model and LlamaChat will download it and run locally with Ollama, featuring a chat interface with all its features: slash commands, tool use, permission modes. It has a Rust core driving a Tauri desktop shell and React UI and uses a Python process to do profiling. Installers for Linux, macOS, and Windows are generated on every release in CI. Offline, without accounts, telemetry, and anything else leaving your computer.

// full-stack · TypeScript · 2026

Rush

Real-time multiplayer "casino" battle royale game where everyone starts with the same play-money bankroll and tries to get to the highest balance before the time runs out. Public matchmaking provides 4-, 8- or 16-player lobbies (filled with CPU bots with unique betting behaviors), or create a private room with kicking and banning options. There are 15+ mini-games ranging from instant games to multi-step and live ones. All outcomes are decided by the server with crypto.randomInt to ensure that no cheating is possible, while balances move with atomicity through Postgres functions to prevent desyncs. Made with Next.js and TypeScript, Supabase for state management, Pusher for live lobby events, custom JWT auth and Vitest/Playwright tests.

// team hackathon · Pitt TLI · 2026

Conjure

Team project
A tool that allows users to sketch the UI of any web application, either on a blank canvas or directly on their existing app, and turn it into a fully functional single-file web application with a live preview right next to them. Markups have semantics: circle something to change it, cross it out to delete, draw an arrow to move it; voice notes can be attached to the sketch, and every change triggers a hot-reload through WebSocket, so the application is created by markups, not prompts. Sites with multiple pages automatically link, and each build is versioned so users can export or roll back their builds. Developed in a weekend by a team of students for the University of Pittsburgh TLI hackathon.

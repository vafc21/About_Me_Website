# About Me

I'm a first-generation student from Pittsburgh, PA, a Junior at Seneca Valley High School with a passion for technology that started early.

At age 7 I was setting up Xbox consoles; by 13 I taught myself to build computers from YouTube tutorials and got my first Arduino, exploring C++. At 14 I moved to Linux on a Raspberry Pi and Ubuntu, skipped the intro Python class at school, and joined an FTC robotics team where I stepped up as head programmer — learning Java on the fly.

Now at 16 I code in multiple languages across robotics, automation, and software. Last summer I attended Pittsburgh Cyber Camp for hands-on cybersecurity.

project-01 AI · Voice · Pi

ClawVIS

Flagship
Always-on voice assistant running on a Raspberry Pi 5 using a three-layer routing system to make it feel instant. The wake word, speech-to-text, and Piper's "JARVIS" voice run on-device; a quick intent matcher answers frequent commands and drives Home Assistant to turn lights and devices on and off without a round trip to the cloud; anything more complex is delegated over SSH to the home server, waking it up over the network if needed. Also includes a phone cockpit with a push-to-talk chat, a WebGL energy orb, and an Obsidian-like memory graph.

project-02 Desktop · Local AI

LlamaChat

Cross-platform desktop application benchmarking your hardware — CPU, GPU, VRAM, RAM, instruction set — then rating all available models from "won't even run" to "flying" for your exact hardware. Download and run locally with Ollama, featuring slash commands, tool use, and permission modes. Built with a Rust core driving a Tauri desktop shell and React UI. Installers for Linux, macOS, and Windows generated on every release in CI. Offline, no accounts, no telemetry.

project-03 Full-stack · Multiplayer

Rush

Real-time multiplayer "casino" battle royale game where everyone starts with the same play-money bankroll and tries to get to the highest balance before time runs out. Public matchmaking provides 4-, 8- or 16-player lobbies filled with CPU bots with unique betting behaviors, or create a private room with kicking and banning. 15+ mini-games, crypto.randomInt server-side outcomes, atomic Postgres balance functions, Pusher for live lobby events, custom JWT auth, and Vitest/Playwright tests.

project-04 Hackathon · Canvas

Conjure

Team project
A tool that lets users sketch the UI of any web application — on a blank canvas or directly on an existing app — and turn it into a fully functional single-file web application with a live preview. Markups have semantics: circle to change, cross out to delete, draw an arrow to move. Voice notes attach to sketches, every change hot-reloads via WebSocket, and each build is versioned. Built in a weekend for the University of Pittsburgh TLI hackathon.
